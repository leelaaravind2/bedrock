# Bedrock — Overview

Bedrock is a **deterministic, AI-free code generator**. You describe an application's shape — its
project type, stack, entities, fields, and relationships — as a **blueprint**, and Bedrock projects
that blueprint to a complete, deployable codebase. The same blueprint always produces **byte-identical**
output. That guarantee is the product.

> **AI guesses; Bedrock knows.**

## The thesis

Reduce AI reliance to only what software cannot do deterministically. Anything with a definite,
certain structure — the shape of a CRUD app across five backend stacks — is generated by a pure
function of the blueprint: free, instant, and reproducible. AI is confined to the few genuinely
creative or advisory gaps, and even there it is optional, detachable, and the developer's own key and
bill. AI is **never** in the generation path ([ADR-001](../adr/ADR-001-ai-is-a-plugin.md); proof:
`CAPABILITIES.md` §3, "no AI in generation; no AI ships").

## The product expression

**The blueprint is the source of truth; source code is a byte-identical projection of it.** Because
generation is a pure function of the blueprint, a blueprint *diff* yields an *exact* output diff —
Bedrock can show you precisely which files a change will touch **before** it generates them (previewed
== real, byte-for-byte; proof: PART 1z, `eco-day-66-report.md`). That is the difference between guessing
and knowing.

## What Bedrock is

- A generator for entity/relationship application shapes on specific stacks: **7 project types × 5
  backend stacks** (Spring Boot, Express, FastAPI, Django, Go), PostgreSQL or MySQL. Coverage and proof
  levels: `CAPABILITIES.md` §2–3.
- A Windows desktop app (Microsoft Store, MSIX). See [01-install-and-first-project.md](01-install-and-first-project.md).
- Certified deterministic: `cd generator && npm run day20:regress` re-proves **103 baked digests + 10
  TeamTracker relationship hashes + non-hash gates, 203 OK / 0 FAIL**, with the crown-jewel MAXIMAL
  digest `366e19d9…` unmoved since Eco-Day 29 (proof: `eco-day-69-report.md` DC-1).

## What Bedrock is NOT (the borders)

- **No AI in the product.** Not in inputs, structure, or the generator's logic. AI only ever fills
  creative *slots* (content, never structure) or *advises* (stamped ADVISORY, never the gate) — default
  off, detachable, developer-keyed.
- **No round-trip.** Generation is one-way. There is no re-parsing of edited code back into a blueprint,
  no protected regions, no model↔code merge.
- **No import of arbitrary code.** Reading an unknown codebase and *guessing* a blueprint is exactly
  what AI does and exactly what Bedrock exists not to do.
- **No universal model.** The blueprint stays narrow and opinionated — depth over breadth.
- **No lock-in.** Export is first-class: delete Bedrock and the exported project still builds and runs
  (Law 21; see [09-export.md](09-export.md)).
